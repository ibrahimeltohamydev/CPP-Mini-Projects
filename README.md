# 🚀 CPP Mini Projects

A collection of small C++ console-based projects built to practice programming fundamentals, problem-solving, file handling, data structures, and system design.

This repository contains multiple mini-projects created to improve my understanding of C++ and strengthen software engineering concepts through practical applications.

---

## 📂 Projects Included

### 🏦 Banking System
A simple banking management system that allows account creation, balance handling, and basic file storage.

**Concepts Used:**
- Structs
- Vectors
- File Handling
- Functions
- Basic CRUD Logic

---

### 🔐 Password Manager
A lightweight console-based password manager for storing, viewing, and searching account credentials.

**Features:**
- Add account
- View saved accounts
- Search by username
- Search by website

**Concepts Used:**
- Structs
- Vectors
- Search Logic
- Menu-driven Programming

---

### 🎓 Student Management System
A GPA and transcript management system for handling students, semesters, courses, and GPA calculations.

**Features:**
- Create student records
- Add semester courses
- Enter scores
- Calculate GPA
- Calculate cumulative GPA
- Save transcript to file
- Load transcript from file

**Concepts Used:**
- Structs
- Arrays
- File I/O
- GPA Logic
- Nested Data Structures
